Marca y proyecto / Brand and project

Preview de fase 1. La integración en las cinco plataformas está pendiente. / Phase 1 preview; platform integration is pending.

Tutorial español

  1. Entra con tu sesión y activa Experto.
  2. Escribe /marca lumbre: cambia la apariencia; tus datos siguen en el mismo proyecto.
  3. Si eres superusuario, escribe /proyecto starbucks: la API devuelve sólo locales alsea-sbux-*.
  4. Abre otra plataforma desde los enlaces: viajan marca y proyecto comprobados.
  5. /marca off restaura el look; /proyecto off elimina sólo el filtro y exige superusuario.

English tutorial

  1. Sign in and enable Expert mode.
  2. Use /brand lumbre to change appearance while keeping your project.
  3. Superusers can use /project starbucks: only alsea-sbux-* locations are returned.
  4. Follow platform links to carry verified brand and project context.
  5. /brand off restores appearance; /project off resets only the filter and requires superuser access.

Si no tienes permiso o el servidor no puede comprobarlo, el proyecto se rechaza. No uses flags de navegador. / Missing permission or unavailable verification rejects the project. Browser flags grant no access.
